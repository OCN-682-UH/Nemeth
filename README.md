# MBIO 612 weekly coursework

This repository includes the scripts, data, and outputs, for the weekly MBIO 612 course assignments.

**Author:** Nicholas "Cameron" Nemeth

**Contents:** All items pertaining to a particular week can be found within that week's folder. Each week's folder contains three sub-folders.

1. **Data:** All of the original data files used in the scripts
2. **Scripts:** All scripts used for the data analyses
3. **Output:** Any figures or tables generated by the code.
